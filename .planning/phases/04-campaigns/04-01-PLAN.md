**## 6. Open Question Resolutions**

Зафиксировать ответы на 5 Open Questions из RESEARCH.md:

| # | Вопрос | Решение | Влияет на план |
|---|--------|---------|----------------|
| Q1 | `message_queue.campaign_id` NULLable vs NOT NULL | **NULLable** (overrides CONTEXT.md D-16 NOT NULL). Причина: D-07 hard delete done кампаний с ON DELETE SET NULL требует NULLable. Альтернатива (NO ACTION + 409 на DELETE если queue items есть) ломает UX. | 04-02 migration |
| Q2 | `POST /campaigns/{id}/duplicate` включить в Phase 4 | **ДА**, в Plan 04-02. Копирует campaigns row + campaign_senders, имя `«{name} (copy)»`, status='draft'. НЕ копирует queue items, НЕ копирует campaign_contact_assignments. | 04-02 |
| Q3 | LLM `text_content + tool_call` одновременно при `finish_conversation` | **Отправить text_content** контакту перед status flip — финальная "прощальная" фраза. | 04-05 |
| Q4 | Workspace-isolation на campaign_senders | API-level validation: POST `/campaigns` валидирует что все `senders[]` принадлежат `ctx.workspace_id` (Phase 1 D-04 паттерн). Defence-in-depth: campaign_senders.workspace_id NOT NULL FK + INSERT всегда заполняет. | 04-02 |
| Q5 | CampaignEnqueueWorker partial failure | INSERT в `campaign_contact_assignments` И INSERT в `message_queue` — в одной транзакции. Если упал — rollback, на следующем tick'е переподхватим. | 04-04 |
| **Q6 (D-04 override)** | `campaigns.status` тип: SQLEnum vs VARCHAR(20)+CHECK | **VARCHAR(20)+CHECK** (overrides CONTEXT.md D-04 «SQLEnum, не String»). Обоснование: (1) PG `ALTER TYPE ADD VALUE` НЕ может выполняться внутри транзакции (RESEARCH.md Pitfall 2) → миграция теряет идемпотентность при будущих расширениях статусов; (2) `conversations.status` уже использует тот же паттерн (Phase 3 — String+CHECK), однородность; (3) C-13 явно перечислил `String + CHECK` как валидную опцию; (4) Lovable UI работает со строками — нет преимущества SQLEnum на API-layer. Принято: оставить `VARCHAR(20)` + CHECK constraint. SQLEnum может быть введён в v2 рефакторинге одним общим migration step (CREATE TYPE + ALTER TABLE TYPE) если потребуется. | 04-02 |
