## Видимость пула — форма ответа кампании

| Option | Description | Selected |
|--------|-------------|----------|
| Агрегат + пер-sender | `pool_health{active,paused,total,earliest_resume_at}` + restriction-поля в attached_senders[] | ✓ |
| Только агрегат | Один объект pool_health, без пер-sender деталей | |
| Только пер-sender | Обогатить attached_senders[], агрегат считать на фронте | |

**User's choice:** Агрегат + пер-sender
**Notes:** Фронт показывает и сводку (бейдж), и кто именно на паузе, без доп-запроса.

## Видимость пула — состояния бейджа

| Option | Description | Selected |
|--------|-------------|----------|
| 3 состояния | Зелёный / жёлтый (частичная пауза) / красный (весь пул стоит) | ✓ |
| 2 состояния | ОК vs есть-ограниченные | |

**User's choice:** 3 состояния
**Notes:** Жёлтый «частичная пауза» — главный сигнал; бинарный бейдж его не различает.
