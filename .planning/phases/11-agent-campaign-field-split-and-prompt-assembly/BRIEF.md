# Phase 11 — Brief: Agent/Campaign Field Split & Prompt Assembly

> Источник: исходное описание фазы от пользователя (2026-06-24). Это вход для `/gsd:plan-phase 11`.

Цель — убрать перегруз и дубли в настройке, чтобы модель перестала ошибаться и вела диалог предсказуемо.

---

## 1. Проблема

Поля «Агента» и «Кампании» размазаны между слоями и дублируют друг друга. Оба слоя склеиваются в один системный промпт, и в него одна и та же мысль попадает 2–3 раза, иногда с противоречиями. GPT-5 mini не умеет выбирать «какая инструкция главнее» — пытается исполнить всё сразу и плывёт.

Лечение — не добавлять поля, а **развести слои и убрать повторы.**

## 2. Принцип разделения

- **Агент = КТО** — стабильная личность, переиспользуется в любой кампании. Здесь нет задачи и нет хода разговора.
- **Кампания = ЧТО** — что делаем именно в этом запуске: задача, ход разговора, цель, факты.
- **Правило:** одно поле = одна мысль, ноль пересечений между слоями.

## 3. Форма «Агент» — новая

| Поле | Тип | Что вкладываем / что меняется |
|---|---|---|
| Название | text | внутренний ярлык, клиент не видит |
| Идентичность | textarea | имя, роль, характер, манера. **Убрать задачу** → в Кампанию |
| Компания | textarea | кого представляет, 1–2 фразы |
| Что продаёт | textarea | продукт + 2–3 ценности (стабильно) |
| Тон | enum | Friendly / Professional / Direct / Casual — **единственный источник тона** |
| Жёсткие правила | textarea | только запреты и стоп-темы; **тон сюда не дублировать** |
| Скорость ответа | enum + ручной ввод | мгновенно / как человек / медленно / **вручную** (задержка в сек) · **NEW** |
| Макс. длина сообщения | number | лимит одного сообщения в символах |

## 4. Форма «Кампания» — новая

| Поле | Тип | Что вкладываем / что меняется |
|---|---|---|
| Агент | select | выбор + опц. override полей агента |
| Кому пишем | textarea | сегмент + контекст; **переименовать** (≠ шаг «Контакты») |
| Цель | enum × 1 | встреча / квалификация / клик / прогрев |
| Ход разговора | steps | 3–5 явных стадий, что делать на каждой · **NEW, ключевое** |
| Аргументы и факты | textarea | факты + пары возражение→ответ, «только это, не выдумывай» · **NEW** |
| Используемые базы знаний | multi-select | какие КБ подтягиваются к кампании · **NEW, будущая фича** |
| Правила кампании | textarea | специфика именно этого запуска |
| Сигнал «Лид» | textarea | когда лид целевой · **= бывш. Success criteria + Lead hint** |
| Сигнал «Передать человеку» | textarea | когда звать менеджера |
| Сигнал «Завершить» | textarea | когда закрывать диалог |

> **Brief + AI auto-fill** оставляем только как генератор черновика полей. В итоговый системный промпт сырой текст брифа **не уходит** — туда идут только структурные поля.

## 5. Чек-лист изменений

- **Убрать** задачу/роль из поля «Идентичность» агента.
- **Слить** «Success criteria» в «Сигнал Лид».
- **Слить** — тон убрать из «Жёстких правил» (тон только в пресете).
- **Переименовать** «Audience hints» → «Кому пишем».
- **Добавить** «Скорость ответа» (с ручным вводом) в Агента.
- **Добавить** «Ход разговора», «Аргументы и факты», «Используемые базы знаний» в Кампанию.
- **Изменить** Brief auto-fill — заполняет поля, но в промпт не попадает.

## 6. Шаги визарда — что трогаем

| Шаг | Статус |
|---|---|
| Brief | изменено (autofill только черновик) |
| Agent | изменено (новая форма + блок поведения) |
| Senders | без изменений — TG-аккаунты-отправители |
| Audience | без изменений — загрузка контактов / базы |
| Schedule | без изменений — дни, часы, таймзона, green corridor, шаблон первого сообщения |
| Integrations | без изменений — внешние подключения / CRM |
| Review | без изменений — финальная проверка перед запуском |

## 7. Сборка итогового системного промпта

Каждый блок имеет ровно один источник. Порядок фиксированный.

```
[ИДЕНТИЧНОСТЬ]                  ← Агент
[КОМПАНИЯ]                      ← Агент
[ПРОДУКТ]                       ← Агент
[ТОН]                           ← Агент (пресет → 1–2 строки)
[ЗАДАЧА КАМПАНИИ + КОМУ ПИШЕМ]  ← Кампания
[ХОД РАЗГОВОРА]                 ← Кампания (стадии по шагам)
[АРГУМЕНТЫ И ФАКТЫ]             ← Кампания + «только это, не выдумывай»
[БАЗА ЗНАНИЙ]                   ← Кампания (будущая фича)
[ПРАВИЛА]                       ← правила агента + кампании, дедуп
[СИГНАЛЫ]                       ← лид / передать / завершить
[ФОРМАТ ОТВЕТА]                 ← Агент (макс. длина, текстовое сообщение)
```
