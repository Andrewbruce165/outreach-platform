### [Rule 3 - Blocking] Sentinel handoff-bundle path resolution

- **Found during:** Task 3 (drafting `test_phase5_1_full_suite.py`)
- **Issue:** Plan's `<action>` used `pathlib.Path("lovable-handoff")` (CWD-relative) which would only work if pytest is invoked from the repo root. Pytest is often invoked from sub-dirs or via IDE integrations where CWD differs.
- **Fix:** Anchored the path to the test file's location: `pathlib.Path(__file__).resolve().parent.parent / "lovable-handoff"` — always resolves to repo-root regardless of CWD.
- **Files modified:** 1 new test file
- **Why not Rule 4:** Pure pathlib idiom; no semantic change to the assertion.
