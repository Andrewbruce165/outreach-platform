# Quick Task 260629-g2z: Multi-tenant prompt template v2

## Goal

Rework `build_system_prompt` onto the multi-tenant v2 scaffold: a universal
static `<core_directive>`, with objective / disclosure / authority rendered from
preset libraries (like `_TONE_LINES`) via four new nullable campaign columns.
Existing campaigns (NULL presets) fall back to safe defaults
(`disclosure→reveal_nothing`, `authority→handoff_only`, `objective→primary_goal`)
and reproduce the prior call-booking text — nothing breaks.

Decisions (user-confirmed):
- core_directive: universal/campaign-agnostic; goal/disclosure/authority in their
  own preset-driven blocks. (D1)
- Few-shot examples: ship BOTH Russian and English static fallback; overridable
  via `campaign.style_examples`. (D2)
- API wiring included now (schemas + router). Frontend (separate repo) out of scope.
- Executed inline with atomic commits.
