<objective>
Enforce a single invariant: a cold-pending `message_queue` row must not sit on an
ineligible (restricted/frozen/paused/auth-failed) sender while the campaign pool has
>=1 eligible sender.

Proven in production 2026-07-06: cold rows got stuck on a `spam_limited` sender even
after healthy senders were attached, because (1) `failover_cold_backlog` only fires
inline at freeze time and never re-runs; (2) `rebalance_on_attach` returns 0 when the
eligible pool has <2 senders (the frozen donor is excluded → P=1); (3) the fair-share
pass moved only a partial share and `ORDER BY scheduled_at DESC` left the now-due row
on the frozen sender; (4) rebalance never reset `scheduled_at`, so an inherited +24h
PEER_FLOOD pause traveled with the moved row.

Purpose: cold contacts keep flowing off dead accounts the moment a healthy sender is
available, whether it was attached before OR after the freeze.

Output: full-evacuation branch in `rebalance_on_attach`, a periodic sweep in the enqueue
worker, and tests. No schema change.
</objective>

    In `app/services/campaign_enqueue.py` add a method to `CampaignEnqueueWorker`:

    ```python
    async def _sweep_stranded_cold_backlog(self) -> int:
        """Re-run failover for every INELIGIBLE sender that still holds cold-pending
        backlog in a running campaign. Closes the gap where failover_cold_backlog only
        fires inline at freeze time and never re-runs (root cause #1). Self-contained:
        the discovery SELECT uses its own session; failover_cold_backlog(db=None) opens
        and commits its OWN session per sender, isolated from the enqueue transaction."""
        from app.services.failover import failover_cold_backlog
        async with AsyncSessionLocal() as db:
            rows = (await db.execute(text("""
                SELECT DISTINCT mq.sender_id AS sid
                FROM message_queue mq
                JOIN senders s   ON s.id = mq.sender_id
                JOIN campaigns c ON c.id = mq.campaign_id
                WHERE mq.status = 'pending'
                  AND mq.item_type = 'message'
                  AND mq.campaign_id IS NOT NULL
                  AND c.status = 'running'
                  AND NOT (
                      s.lifecycle_status = 'active' AND s.auth_status = 'ok'
                      AND s.role = 'sender' AND s.restriction_status = 'none'
                  )
            """))).fetchall()
        total = 0
        for r in rows:
            total += await failover_cold_backlog(r.sid)
        if total:
            logger.info(
                "📤 sweep: evacuated %d stranded cold-pending rows off ineligible senders",
                total,
            )
        return total
    ```

    try:

    except Exception as exc:  # noqa: BLE001 — sweep must not starve enqueue
