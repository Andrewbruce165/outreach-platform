# Quick Task 260630-e02 — Summary

## What was built
Удаление диалогов из инбокса — одиночное и массовое, hard delete (как
существующий `DELETE /conversations/{id}`: каскадом сносит беседу + сообщения +
LLM-лог из нашей БД; Telegram-диалог не затрагивается).

## Changes

### Backend (`/root/apps/aimly/tg-outreach`, remote outreach-platform) — commit 4084e92
- `app/schemas/__init__.py`: `DeleteConversationsBatchRequest { conversation_ids: List[UUID] (min_length=1) }`.
- `app/routers/conversations.py`: новый `POST /api/v1/conversations/delete` (`delete_conversations_batch`) — workspace-scoped, один `DELETE … RETURNING` (SQLAlchemy Core), DB-level FK CASCADE сносит messages + llm_calls, возвращает `{deleted: N}`. Cross-tenant ids молча пропускаются (зеркало `contacts.delete_contacts_batch`). Статический путь `/delete` объявлен до `DELETE /{conversation_id}`, конфликта нет (метод POST).
- `tests/test_phase5_inbox.py`: `test_delete_conversations_batch_happy_path` + `test_delete_conversations_batch_cross_workspace_skipped`.

### Frontend (`/root/apps/aimly/aimly-tg-outreach`, remote AGS-Venture-Lab) — commit d3694ec
- `src/routes/_authenticated/inbox.tsx`:
  - Одиночное: иконка-корзина по hover на строке чата → `AlertDialog` → `DELETE /conversations/{id}`.
  - Массовое: кнопка «Select» включает режим с чекбоксами на строках + select-all + панель «Delete (N)» → `AlertDialog` → `POST /conversations/delete`.

  - Паттерн зеркалит существующую страницу `contacts.tsx` (selected Set, allVisibleSelected, bulk-bar, toast, Trash2).
