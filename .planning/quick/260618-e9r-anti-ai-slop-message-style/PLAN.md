# Quick Task: anti-AI-slop в дефолтном стиле общения

Расширить дефолтную константу `_PROMPT_MESSAGE_STYLE` в `app/services/ai_engine.py`
анти-AI-слоп паттерном, адаптированным под Telegram-сообщения (1–3 предложения).

## Scope (подтверждено пользователем: «Адаптированный для чата»)

Добавить в `<message_style>`:
1. Типографика — тире «—» с пробелами, запрет «--», ёлочки «…» вместо прямых кавычек,
   символ многоточия «…» вместо трёх точек. Критично для русскоязычных ответов.
2. Запрещённая лексика — русская таблица (Важно отметить, Стоит отметить, Давайте
   рассмотрим, Таким образом, Безусловно, Данный, Осуществлять, …) + английская
   (delve, leverage, robust, crucial, it's worth noting, …).
3. Ограничение «однако»/«например» — не чаще одного раза.
4. Естественность — без фальшивого энтузиазма и избыточного хеджирования.

НЕ добавляем: структурные правила про абзацы, отступления, число пунктов в списках,
адаптацию под типы текстов — неприменимо к чату по 1–3 предложения.

## Файл

- `app/services/ai_engine.py:406` — константа `_PROMPT_MESSAGE_STYLE`

## Verify

- `python -c "import app.services.ai_engine"` импортируется без ошибок
- `_PROMPT_MESSAGE_STYLE` непустая, содержит русскую запрещённую лексику и правило тире
