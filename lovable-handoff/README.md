# aimly — Lovable Handoff Bundle

Generated from outreach-platform backend at commit a23399f. Source of truth for the Lovable build.

## How to consume

1. Copy `AGENTS.md` to the root of your Lovable project (Lovable always reads root AGENTS.md).
2. Paste `KNOWLEDGE.md` content into your Lovable project Knowledge field (Settings → Knowledge).
3. Reference `screen-build-order.md` — build screens one-at-a-time, smoke-test each against the staging backend before starting the next.
4. Import types from `types/api.ts` — never invent backend response shapes (AGENTS.md rule 1).
5. Copy `design-source/` into the Lovable project so `design-source/project/styles.css` can be imported as the design token source.

## What's in this bundle

- `AGENTS.md` — Lovable agent always-read rules
- `KNOWLEDGE.md` — workspace Knowledge field content (<=10K chars)
- `openapi.json` — exported from FastAPI; source of truth for paths and shapes
- `types/api.ts` — generated by openapi-typescript from openapi.json
- `.env.example` — VITE_SUPABASE_URL + VITE_SUPABASE_ANON_KEY + VITE_BACKEND_URL
- `screen-build-order.md` — 11 screens with per-screen build prompts and dependencies
- `error-codes.md` — `{code, message}` envelope → UI-SPEC §8.3 friendly strings
- `telemetry-events.md` — 17 events with fire triggers and props shape
- `reconciliation.md` — UI-SPEC path patches (changelog)
- `design-source/` — copied from `.planning/phases/05.1-lovable-ui-v1/design-source/`

## Regenerating

From the backend repo root:

```
bash scripts/export-handoff.sh
```

Requires Docker (for `docker compose up api`), Node 18+ (for `npx openapi-typescript`), Python 3.11 (for `scripts/check-uispec-endpoints.py`).
