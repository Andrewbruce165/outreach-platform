# Итоги — 18 февраля 2026

## Задача → Результат

**Задача:** Аккаунты Telegram банят из-за массовой отправки
**Результат:** Очередь на PostgreSQL + воркер с rate limit (12 сек/сообщение, 30 msg/час на аккаунт). Отправка автоматически замедляется до безопасного темпа.

---

**Задача:** Импорт контактов при каждой отправке — сигнал для спам-детектора Telegram
**Результат:** Заменили `ImportContactsRequest` на `ResolvePhoneRequest`. Контакты больше не импортируются в адресную книгу. Попутно исправлена ошибка `PeerUser entity not found`.

---

**Задача:** Агент отвечал через 5 секунд — слишком быстро, выглядит как бот
**Результат:** Задержка увеличена до 3 минут. Агент накапливает все сообщения и отвечает одним сообщением через 3 мин после последнего.

---

**Задача:** n8n делал polling каждые 5 секунд для проверки статуса отправки
**Результат:** Добавили `callback_url` в запрос. API сам вызывает вебхук n8n когда сообщение доставлено (или упало с ошибкой). Polling не нужен.

---

**Задача:** Сообщения могли уйти ночью
**Результат:** Отправка только с 09:00 до 20:00 МСК. Ночные сообщения ждут в очереди до утра.
