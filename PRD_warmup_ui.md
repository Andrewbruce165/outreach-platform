# PRD — Warmup UI (Lovable)

## Обзор

Интерфейс управления прогревом Telegram-аккаунтов. Позволяет добавлять аккаунты в пул прогрева, отслеживать прогресс и видеть статистику. Прогрев — это автоматические AI-диалоги между нашими аккаунтами, которые делают их «живыми» перед началом рассылок.

---

## Технические требования

- **API Base URL:** `http://<server>:8000`
- **Auth header:** `X-API-Key: <key>` (на все запросы)
- **Стек:** React + TypeScript, Tailwind CSS, shadcn/ui компоненты
- **Обновление данных:** polling каждые 30 секунд (не WebSocket)

---

## Страницы и компоненты

### 1. Главная страница `/warmup`

Делится на два блока: **Сводка** (вверху) и **Аккаунты** (основной список).

---

#### 1.1 Блок «Сводка» (Stats Bar)

4 карточки в ряд:

| Карточка | Что показывает | API поле |
|----------|---------------|----------|
| 🔥 Аккаунтов в прогреве | Число активных | `stats.active_accounts` |
| 💬 Сообщений сегодня | Всего за день | `stats.messages_today` |
| 🔄 Активных сессий | Текущие диалоги | `stats.active_sessions` |
| ✅ Завершено сегодня | Сессий за день | `stats.sessions_completed_today` |

**API:** `GET /api/v1/warmup/stats`

---

#### 1.2 Таблица аккаунтов

**API:** `GET /api/v1/warmup/pool`

Каждая строка — один аккаунт (sender с role='sender').

Колонки:

| Колонка | Данные | Примечание |
|---------|--------|------------|
| Аккаунт | `name` + `phone` в подстроке | |
| Статус | Badge: «В прогреве» / «Пауза» / «Не добавлен» | см. ниже |
| Уровень | 1–5 с иконкой огня | `level` (null если не в пуле) |
| Дней в прогреве | `enrolled_days` | только если в пуле |
| Сообщений сегодня | `sent_today` | |
| Действия | Кнопки | |

**Логика статус-бейджа:**
- `in_pool = false` → серый «Не добавлен»
- `in_pool = true AND warmup_active = true` → зелёный «Активен»
- `in_pool = true AND warmup_active = false` → жёлтый «Пауза»
- `is_active = false` (сам аккаунт неактивен) → серый «Аккаунт отключён» + строка disabled

**Кнопки действий:**
- Если `in_pool = false`: кнопка **«Добавить в прогрев»** (синяя)
- Если `in_pool = true AND warmup_active = true`: кнопка **«Пауза»** (жёлтая) + кнопка **«Удалить»** (красная, с подтверждением)
- Если `in_pool = true AND warmup_active = false`: кнопка **«Возобновить»** (зелёная) + кнопка **«Удалить»** (красная, с подтверждением)

**Индикатор уровня (Level Badge):**

```
Уровень 1 🔥     — серый   (первые 3 дня)
Уровень 2 🔥🔥   — голубой (4–7 дней)
Уровень 3 🔥🔥🔥 — синий   (8–14 дней)
Уровень 4 🔥🔥🔥🔥 — оранжевый (15–21 день)
Уровень 5 🔥🔥🔥🔥🔥 — зелёный (готов к работе, 22+ дней)
```

---

### 2. Секция «Активные диалоги» (на той же странице, под таблицей)

**API:** `GET /api/v1/warmup/sessions`

Карточки активных сессий. Каждая карточка:

```
┌─────────────────────────────────────────────┐
│  account_slug_a  ↔  account_slug_b          │
│  Тема: «планы на выходные»                  │
│                                             │
│  ████████░░░░░░░  5 / 8 сообщений           │
│                                             │
│  Следующее: через 47 мин                    │
└─────────────────────────────────────────────┘
```

- Progress bar: `messages_sent / target_messages`
- Время до следующего сообщения: вычислять из `next_message_at` относительно `now()`
  - Если `next_message_at` в прошлом → «Скоро»
  - Иначе → «через X мин» или «через X ч Y мин»

Если активных сессий нет — пустое состояние: «Сессии запустятся автоматически когда придёт время»

## API endpoints

### Получить список аккаунтов с warmup-статусом
```
GET /api/v1/warmup/pool
Headers: X-API-Key: ...

Response 200:
{
  "senders": [
    {
      "id": "uuid",
      "slug": "account-1",
      "name": "Иван Петров",
      "phone": "+79991234567",
      "is_active": true,
      "in_pool": true,
      "warmup_active": true,
      "enrolled_at": "2026-02-20T10:00:00Z",
      "enrolled_days": 5,
      "level": 2,
      "sent_today": 14
    }
  ]
}
```

### Добавить в пул
```
POST /api/v1/warmup/pool/{sender_id}
Headers: X-API-Key: ...

Response 201:
{ "status": "added", "sender_id": "...", "slug": "..." }
```

### Удалить из пула
```
DELETE /api/v1/warmup/pool/{sender_id}
Headers: X-API-Key: ...

Response 204 (no body)
```

### Переключить активность (пауза / возобновить)
```
PATCH /api/v1/warmup/pool/{sender_id}/toggle
Headers: X-API-Key: ...

Response 200:
{ "sender_id": "...", "warmup_active": true }
```

### Статистика
```
GET /api/v1/warmup/stats
Headers: X-API-Key: ...

Response 200:
{
  "active_accounts": 3,
  "active_sessions": 1,
  "messages_today": 47,
  "sessions_completed_today": 4,
  "accounts": [
    { "slug": "account-1", "name": "Иван", "sent_today": 14, "enrolled_days": 5, "level": 2 }
  ]
}
```

### Активные сессии
```
GET /api/v1/warmup/sessions
Headers: X-API-Key: ...

Response 200:
{
  "sessions": [
    {
      "id": "uuid",
      "topic": "планы на выходные",
      "messages_sent": 5,
      "target_messages": 8,
      "next_message_at": "2026-02-25T14:32:00Z",
      "sender_a": "account-1",
      "sender_b": "account-2",
      "progress_pct": 62
    }
  ]
}
```

## UX детали

### Диалог подтверждения удаления
При нажатии «Удалить из прогрева»:
```
Удалить из прогрева?
Аккаунт «Иван Петров» будет удалён из пула.
Активные сессии будут завершены. Прогресс дней сбросится.

[Отмена]  [Удалить]
```

### Toast-уведомления
- Добавить → «✅ Иван Петров добавлен в прогрев»
- Пауза → «⏸ Прогрев приостановлен»
- Возобновить → «▶ Прогрев возобновлён»
- Удалить → «🗑 Удалён из прогрева»

### Пустые состояния
- Нет аккаунтов с role='sender': «Добавьте аккаунты через раздел "Аккаунты"»
- Нет аккаунтов в пуле: «Добавьте аккаунты в прогрев кнопкой выше»

### Автообновление
Данные обновляются автоматически каждые 30 секунд.
Индикатор последнего обновления: «Обновлено X сек назад» в правом верхнем углу.

## Дизайн-указания

- Тёмная тема (или светлая — на усмотрение)
- Акцентный цвет: оранжевый / огненный (тематика прогрева)
- Иконка раздела: 🔥 или flame из lucide-react
- Компоненты: shadcn/ui (Table, Card, Badge, Button, Progress, Dialog)

---

## Что НЕ нужно в первой версии

- Ручной выбор пар (пары создаются автоматически)
- Просмотр текстов сообщений (конфиденциально)
- Настройка расписания (задержки захардкожены)
- Изменение уровня вручную (автоматически по дням)
